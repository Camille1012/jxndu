## 首次开启 Pages（仓库 Settings 里点一下即可）

1) 打开 https://github.com/Camille1012/jxndu/settings/pages
2) Source 选「Deploy from a branch」
3) Branch 选 main / (root)，Save
4) 等绿色横幅显示 Your site is live，即可访问上面的永久链接。
